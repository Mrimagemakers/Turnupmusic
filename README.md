# Turn Up Music

Internet radio with a 3D VR Lounge, Stage visuals and artist profiles. By PenGame Publishing.

Live: https://mrimagemakers.github.io/turnupmusic/

- Meta Quest 3: open the link in the Meta Quest Browser, tap **VR Lounge**, then **Enter VR** (or **Place in my room (AR)** for passthrough).
- Add `#lounge` to the link to open straight into the lounge.
